# Digital Receipt System (DRS)

## Project Overview
Digital Receipt System is a full-stack application designed to digitize donation receipt management for Ganesh Mandals, temples, trusts, NGOs, and other organizations. It simplifies donor management, receipt generation, and collection tracking.

## Technology Stack
- **Frontend:** React.js, JavaScript, HTML, CSS, Bootstrap
- **Backend:** Java, Spring Boot, Spring Data JPA, REST APIs
- **Database:** MySQL
- **Android:** Android Studio
- **Deployment:** AWS EC2, Nginx

## Key Features
- Donor management and record maintenance
- Digital donation receipt generation
- PDF receipt generation and WhatsApp sharing
- Daily collection tracking
- Donation and receipt history
- REST API-based frontend and backend integration

## Deployment
The application backend is deployed on AWS EC2 using Nginx.
